Eleven scenes that listen.

GPU visualizers driven by live FFT analysis — spectrum, waveform, band energy and beat detection, all running on one WebGL context. Start the built-in demo track, or feed it your own audio.

Drop-in component

Paste it into Base44 and wire it to your player.

Everything above is one self-contained React component — no npm packages, no three.js, no CDN. It renders with raw WebGL and taps the Web Audio graph your player already has. Point it at your <audio> element and it starts reacting.

Zero dependencies

React and the browser. Nothing to install, nothing to bundle, nothing that can break your build.

One canvas, eleven scenes

All presets share a single GL context, audio texture and bloom chain. Switching is instant and allocation-free.

Adapts to the device

Render scale, particle counts and mesh density scale with quality, and drop automatically if frame rate sags.

Non-destructive audio tap

The analyser sits alongside your output, so playback stays audible and untouched. Streams and mic input work too.

Create the file

In Base44, add components/AudioVisualizer.jsx and paste the copied source.

02

Import it where your player lives

import AudioVisualizer from "@/components/AudioVisualizer";

03

Hand it your audio element

Pass the same <audio> ref your player controls. The component taps it once and reuses that node forever after.

04

Pick your defaults

Set mode, palette, intensity and quality, or leave the built-in controls on and let listeners choose.

// Base44 page — the visualizer as your player's backdrop
import React, { useRef } from "react";
import AudioVisualizer from "@/components/AudioVisualizer";

export default function NowPlaying({ track }) {
  const audioRef = useRef(null);
  return (
    <div className="relative h-screen w-full bg-black">
      <AudioVisualizer
        audioRef={audioRef}
        mode="aurora"
        palette="ultramarine"
        intensity={1.15}
        quality="high"
        showControls
        className="absolute inset-0"
      />
      <audio ref={audioRef} src={track.url} controls autoPlay />
    </div>
  );
}
